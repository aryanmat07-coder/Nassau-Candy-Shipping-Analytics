# 🚚 Nassau Candy Shipping Analytics Dashboard

An interactive Streamlit dashboard for analyzing factory-to-customer shipping performance across the United States.

## Features

- 📊 KPI Dashboard
- 🚚 Route Efficiency Analysis
- 🏭 Factory Performance Analysis
- 🌎 Geographic Shipping Analysis
- 🗺️ US Shipment Volume Map
- 🚨 US Delay Rate Map
- 📦 Ship Mode Comparison
- 🔎 Route Drill-Down
- 📥 Download Filtered Data

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
